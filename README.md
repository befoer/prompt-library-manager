# Prompt Library Manager（词库管理器）

本地运行的 **Prompt / Tag 文本词库管理工具**，用于管理 ComfyUI Wildcard / 文本列表批量随机生成使用的 TXT 词库。

> **重要**：这不是训练集 caption 管理器，也不是图片标注工具。TXT 与图片无任何关联。
> **一行 = 一个随机候选项**。`Fantasy Room, messy room, Strange Plants` 是一整行，就是一个候选项，
> 绝不把行内逗号拆开，导出 TXT 时也只输出原始文本（不输出 JSON / 翻译 / ID）。

---

## 快速开始

```bat
run.bat        :: Windows 一键启动（自动装依赖）
```

或手动：

```bat
pip install -r requirements.txt
python main.py
```

技术栈：Python 3.10+ / PySide6（Qt）。纯本地运行，无云依赖。

## 已实现功能

### Phase 1 —— 核心编辑
- 文件夹模式：打开词库目录，左侧列出全部 `*.txt`；新建 / 重命名 / 删除 / 刷新词库
- Entry 编辑：整行为一个条目；双击 / Enter 行内编辑（Enter 保存、Esc 取消）
- 新增、删除、批量删除（勾选后删除，带确认）、右键菜单（编辑 / 复制 / 删除）
- 实时搜索：**包含**（默认，不区分大小写）/ 前缀 / 精确 / 正则
- 去重（保留首次出现，先提示数量再确认）
- 排序：原始顺序（可恢复）/ A→Z / Z→A / 中文拼音 / 长度 / 随机
- 拖拽排序（保存后 TXT 顺序同步改变）
- 导入 TXT（自动清理：CRLF/LF/CR、UTF-8 BOM、首尾空格、空行）
- 导出 TXT（仅 text 字段，UTF-8，原子写入）
- 编码自动识别：UTF-8 / UTF-8 BOM / UTF-16 / GBK(GB18030)
- 🎲 随机抽取（单条 / 多条）
- `Ctrl+S` 保存、`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做（基于内容指纹的脏标记，撤销回已保存状态自动清除）
- 外部修改检测：无未保存修改时自动重载；有修改时弹出 [重新载入 / 保留当前修改 / 查看差异]
- 拖拽 TXT / 文件夹到窗口打开
- QListView 虚拟滚动：20 万行加载 0.3s、搜索 0.05s、排序 0.15s、撤销全删 0.07s

### Phase 2 —— 批量操作
- **批量替换**：不区分大小写；可选「当前词库」（可撤销）或「所有词库」（直接写文件，先统计再确认）
- **批量复制 / 移动到其他词库**：目标词库下拉选择；移动时源词库可用 Ctrl+Z 撤销
- 导出 TXT 支持任意路径

### Phase 3 —— 中文翻译
- **双语显示**：列表双行（英文 + 中文），状态圆点：灰=未翻译，绿=已翻译，橙=翻译需更新（原文被修改后自动标记，旧翻译保留不删除）；工具栏「中文」复选框可切换单/双行
- **离线词典翻译**：自动加载 `Tags/zh-CN.txt`（约 2.4 万条英中对照）+ danbooru/e621 别名表（先把别名归一化到规范 tag 再查词）；多 tag 条目逐项翻译后拼接，缺词保留英文
- **AI 批量翻译**：OpenAI 兼容 API（Base URL / API Key / Model 自定义）或 **百度翻译**（AppID/密钥）；并发批量请求、失败逐条重试
- **翻译缓存**：结果自动写入本地 JSON（AppData），下次直接命中不重复请求；可一键清空
- **翻译旁车文件**：翻译不写入 TXT，单独存 `<词库名>.txt.zh.json`，重启自动恢复；修改原文不会丢旧翻译
- 翻译设置对话框：测试连接、词典目录选择、缓存管理
- 翻译全部未翻译 / 翻译选中 / 离线翻译选中 / 编辑翻译 / 清除翻译，全部可 Ctrl+Z 撤销

### Phase 4 —— CSV / 统计 / 合并 / 差异
- **CSV 导入导出**：英中对照（第一列 English、第二列 Chinese，自动跳过表头）；
  导入时已有条目更新翻译、没有的追加为新条目（可撤销）；导出含表头，Excel 友好
- **Tag 统计**：按逗号统计当前词库内 tag 频率（只读分析，绝不拆分条目）
- **词库合并**：多选词库合并到当前词库（可撤销）或另存为新文件，可选去重
- **词库差异比较**：两个词库的增删统计 + 逐行 diff 预览（超大词库自动退化为集合统计）

### 快捷键

## 数据安全

- TXT 是唯一数据源；导出/保存永远是纯文本 `entry` 列表，ComfyUI 可直接读取
- 保存采用「临时文件 + 原子替换」，不会写坏词库
- 翻译只存在旁车文件（`*.txt.zh.json`）与缓存中，删除即可丢弃
- 程序检测外部修改，不会无提示覆盖你正在编辑的文件

```
│   │   ├── commands.py     # 撤销命令（增删改/排序/翻译/替换）
│   │   ├── dictionary.py   # 离线英中词典 + 别名归一化
│   │   ├── ai_translate.py # OpenAI 兼容 / 百度 + 缓存 + 批量工作线程
│   │   └── library_ops.py  # 跨词库复制移动 / 文件级批量替换
│   └── ui/
│       ├── main_window.py  # 主窗口 / 菜单 / 快捷键 / 文件监视
│       ├── entry_view.py   # 虚拟列表 + 自绘 delegate（双语 / 状态点）
│       ├── entry_model.py  # 列表模型 + 过滤 + 拖拽 MIME
│       ├── sidebar.py      # 左侧词库列表
│       ├── dialogs.py      # 随机抽取 / 差异查看 / 确认
│       └── translate_dialogs.py  # 翻译设置 / 批量替换 / 复制移动
├── tests/smoke_test.py     # 冒烟测试（95 项）
├── txt/                    # 示例词库（用户数据，不入库）
└── Tags/                   # 翻译词典资源（用户数据，不入库）
```
